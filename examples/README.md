# QYVORA Sentinel Examples

Example scripts demonstrating common Sentinel usage patterns.

## Scripts

| Script | Description |
|--------|-------------|
| `quick_scan.sh` | Fast security scan with medium+ severity |
| `full_audit.sh` | Comprehensive audit with all report formats |
| `module_example.sh` | Template for creating new scan modules |

## Running Examples

```bash
# Quick scan
./examples/quick_scan.sh

# Full audit
./examples/full_audit.sh
```

## Creating Custom Scripts

Copy `module_example.sh` as a starting point for your own automation scripts.
